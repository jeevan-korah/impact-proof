FINE-TUNING STRATEGY WITH RLHF/DPO:
- Use Direct Preference Optimization (DPO) over traditional RLHF for efficiency
- Methodology:
  * Collect preference dataset: 50K high-quality prompt-response pairs
  * Human annotators rank responses (A vs B)
  * Train with DPO loss: L = -log(σ(β(log π(y_w|x) - log π(y_l|x))))
  * β = 0.1 (KL penalty coefficient)
  * Learning rate: 5e-6 with cosine decay
  * 3 epochs over preference data
- Reward model architecture: Claude base + 2-layer MLP classifier
- Avoid reward hacking with KL divergence constraint

```python
# Speculative decoding
def speculative_decode(draft_model, target_model, prompt, k=5):
    # Draft model generates k tokens quickly
    draft_tokens = draft_model.generate(prompt, max_new_tokens=k)
    
    # Target model verifies in parallel
    verified = target_model.verify(draft_tokens)
    
    return verified
```
