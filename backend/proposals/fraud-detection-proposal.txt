OBJECTIVE:
Improve fraud detection model to reduce false positive rate from 12% to under 3% while maintaining 99.5% detection accuracy for actual fraud cases.

FEATURE ENGINEERING APPROACH FOR TRANSACTION PATTERNS:
- Time-based features:
  * Hour of day, day of week patterns
  * Time since last transaction
  * Transaction velocity (count in last 1h, 24h, 7d)
  * Unusual time patterns (3am purchases)

- Amount-based features:
  * Deviation from user's average transaction
  * Z-score of transaction amount
  * Running statistics (mean, std, median)
  * Ratio to user's historical max/min

- Location-based features:
  * Distance from previous transaction
  * IP geolocation mismatch with card location
  * Velocity impossible (e.g., 1000km in 1 hour)
  * Known high-risk regions

- Behavioral features:
  * Merchant category changes
  * First time merchant/category for user
  * Device fingerprint matching
  * Failed authentication attempts

```python
import pandas as pd
import numpy as np

def engineer_features(transaction, user_history):
    features = {}
    
    # Velocity features
    features['tx_count_1h'] = len(user_history.last('1h'))
    features['tx_count_24h'] = len(user_history.last('24h'))
    
    # Amount deviation
    user_avg = user_history['amount'].mean()
    features['amount_zscore'] = (transaction['amount'] - user_avg) / user_history['amount'].std()
    
    # Location velocity
    if len(user_history) > 0:
        last_tx = user_history.iloc[-1]
        distance = haversine(last_tx['location'], transaction['location'])
        time_diff = (transaction['timestamp'] - last_tx['timestamp']).seconds / 3600
        features['location_velocity'] = distance / max(time_diff, 0.1)
    
    # Pattern detection
    features['is_unusual_hour'] = transaction['hour'] in [0, 1, 2, 3, 4, 5]
    features['is_new_merchant'] = transaction['merchant_id'] not in user_history['merchant_id'].unique()
    
    return features
```

```python
# Focal loss for neural network
import torch.nn as nn

class FocalLoss(nn.Module):
    def __init__(self, alpha=0.25, gamma=2):
        super().__init__()
        self.alpha = alpha
        self.gamma = gamma
    
    def forward(self, inputs, targets):
        bce_loss = nn.BCEWithLogitsLoss(reduction='none')(inputs, targets)
        pt = torch.exp(-bce_loss)
        focal_loss = self.alpha * (1 - pt) ** self.gamma * bce_loss
        return focal_loss.mean()
```

PRECISION-RECALL TRADEOFF ANALYSIS:
- Current operating point:
  * Precision: 30% (70% false positive rate = 100% - 30%)
  * Recall: 99.8% (detection rate)

- Target operating point:
  * Precision: 97% (3% false positive rate)
  * Recall: ≥99.5% (maintain detection accuracy)

- Strategy:
  * Adjust decision threshold from 0.5 to 0.85
  * Use precision-recall curve to find optimal threshold
  * Business cost function: Cost(FP) = $5, Cost(FN) = $500
  * Optimize F-beta score (β=10 to weight recall higher)

```python
from sklearn.metrics import precision_recall_curve
import matplotlib.pyplot as plt

# Find optimal threshold
precisions, recalls, thresholds = precision_recall_curve(y_true, y_probs)

# Calculate F-beta score for each threshold
beta = 10  # Weight recall 10x more than precision
f_beta_scores = (1 + beta**2) * (precisions * recalls) / (beta**2 * precisions + recalls)

optimal_idx = np.argmax(f_beta_scores)
optimal_threshold = thresholds[optimal_idx]

print(f"Optimal threshold: {optimal_threshold:.3f}")
print(f"Precision: {precisions[optimal_idx]:.1%}")
```
